# Optional integrations

CaseKit remains the source of truth. External suites may execute specialist work but must return changes through CaseKit IDs and handoff blocks.

## gstack

Use gstack after strategic choice and MVP scope are stable:

| CaseKit stage | Optional gstack capability |
|---|---|
| Discovery challenge | office-hours or CEO review |
| Technical plan | engineering review |
| Prototype UX | design consultation/review |
| Working demo | report-only QA, security review, performance benchmark |
| Code delivery | review and ship workflow |

Do not require gstack for non-code cases. Do not let external output replace CaseKit ledgers. Record discovered defects as Risks or Decisions, and return cost/capacity changes to Finance.

Project and installation instructions: https://github.com/garrytan/gstack. It supports Codex as a host; install and update it separately rather than vendoring it into CaseKit.

## startup-skill

CaseKit includes original competition-focused adaptations of useful discovery, research-depth, competitor, positioning, finance-stage, and pitch-variant patterns. Installing startup-skill is optional. If invoked separately, import only verified findings into the Evidence and Assumption Ledgers and resolve conflicts before downstream work.

Project: https://github.com/ferdinandobons/startup-skill

## Conflict rule

When outputs disagree, prefer direct case evidence, then authoritative current sources, then transparent derived estimates, then transferable benchmarks, then team judgment. Record the decision instead of merging incompatible values.
