# Team draft folders

Create one folder per person. Examples:

```text
00-INBOX/
├── finance-may/
├── product-nut/
├── growth-beam/
└── pitch-fah/
```

Put all unfinished work here: AI Markdown, notes, research links, calculations, screenshots, and candidate ideas. A draft here is safe to discuss but is not an official case claim, number, or slide.

When you finish a draft, commit and push only your own folder, then tell the Integrator what you recommend and where the evidence lives. The Integrator promotes only the agreed parts into the root official files.
