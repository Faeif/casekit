▼

Move 3 (Sensitivity Bound): RSK-001 caps retry attempts at 3 with exponential backoff before dead-lettering.

Move 4 (Validated Action): Automated integration test suite tests 504 failure simulation in CI.

Move 3 (Sensitivity Bound): Data export uses standard CSV/webhook connectors while formal ERP integration queues.

Move 4 (Validated Action): Phase 1 pilot limits pilot to 500 records to prove ROI before enterprise API lock.
